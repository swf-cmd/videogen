## videogen の特長

- **1 本ずつではなく、まとめて。** 空行で区切ったプロンプトを貼り付けるか、テンプレート変数入りの UTF-8 CSV と画像フォルダーを取り込みます。行ごとに開始フレーム（モデルが対応していれば終了フレームも）を指定でき、「プロンプトごとのテイク数」で各行を 1〜20 回生成できます。
- **良いテイクをすばやく選ぶ。** 完成した動画はショット・テイクごとにギャラリーへ並びます。**J/K** で移動、**Space** で再生、**1** で採用、**2** で不採用。採用したテイクはパス・プロンプト・設定・SHA-256 付きの CSV / JSON で書き出して編集ソフトへ渡せます。
- **送信前に費用がわかる。** 各行をモデルの対応機能で検証し、見積もってから送信します。合計は送信ボタン横のスレートに表示されます。バッチ予算と、採用 1 本あたりの推定費用も確認できます。不明な料金は推測せず「不明」と表示します。
- **二重課金を起こさない設計。** キューはローカルのサービスが持つため、ブラウザーを閉じても影響はなく、クラッシュや再起動後も既知のジョブを追跡し続けます。結果が不明な生成要求は自動で再送せず、判断を待ちます。SIGKILL による再起動を含む 100 ジョブの試験で重複作成は 0 件でした。
- **ローカルで完結、プライバシーを保護。** サービスは `127.0.0.1` だけで待ち受けます。キーはメモリー上だけに保持され、プロンプトや画像、履歴は自分のデータフォルダーに残ります。アカウント登録、テレメトリー、更新チェック、npm 依存はありません。
- **複数のプロバイダーを同じ手順で。** 日付付きの同梱カタログには OpenRouter・Gemini・Model Studio・Ark の動画モデル 31 種（Veo 3.1、Kling 3.0、Seedance 2.5、Wan 3.0、Runway Gen-4.5 など）が載っており、自前の OpenAI 互換サーバーも使えます。[詳細（英語）](README.md#providers-and-estimates)

## 起動

**インストール不要版：** [Releases](https://github.com/swf-cmd/videogen/releases/latest) から Windows x64 または macOS universal の ZIP をダウンロードし、書き込み可能なフォルダーにすべて展開します。Windows は **Start videogen.cmd**、Mac は **Start videogen.command** をダブルクリックしてください。Node 24 LTS が同梱され、Apple Silicon と Intel Mac の両方に対応します。

OS が初回起動の確認を求めることがあります。macOS では「システム設定 → プライバシーとセキュリティ → このまま開く」を確認してください。この ZIP は公証済みの `.app` ではありません。詳細とチェックサムは [ポータブル版の説明](docs/PORTABLE.md) を参照してください。

**ソース版：** Node `^22.21.0 || >=24.5.0` が必要です。Node 18、20、23 は非対応です。`npm install` は不要です。

```bash
git clone https://github.com/swf-cmd/videogen.git
cd videogen
npm start
```

表示されたローカル URL（通常 `http://127.0.0.1:5177`）を開きます。処理中はターミナルを開いたままにし、停止するときは Ctrl+C を押し、進行中の処理の記録が終わるまで最大 15 秒待ってください。保存先にはハードリンクが必要で、exFAT は非対応です。ブラウザーを閉じてもサービスのキューは動作します。ポータブル版の記録は `portable-data/`、動画は `portable-output/` に保存されます。ソース版の動画保存先は `~/Downloads/videogen` です。

## 画面の見かた

画面は左の**新しいバッチ**と右の**レンダーキュー**の 2 ペインです。広い画面では各ペインが個別にスクロールし、幅 1,100 px 未満では 1 列になって上部に「新しいバッチ · レンダーキュー」の切り替えが表示されます。OS のライト／ダーク設定に従い、「動きを減らす」設定ではアニメーションを止めます。表示言語は日本語・英語・中国語・韓国語をいつでも切り替えられます。

| 新しいバッチのステップ | 設定する内容 |
| --- | --- |
| **1 · モデルとキー** | プロバイダー・地域、モデル、そのレーンの API キーとエンドポイント。互換サーバーではモデル ID、対応機能、リクエスト形式も指定します。 |
| **2 · ショットを書く** | 空行で区切ったプロンプトと、任意の共通開始フレーム。「タスク別編集と一括インポート」で CSV、プロンプトテンプレート、画像フォルダーの対応付け、行ごとの開始・終了フレームを扱います。 |
| **3 · 映像とテイク** | 長さ、解像度、アスペクト比、「プロンプトごとのテイク数」（1〜20）。モデルが対応していれば音声とシードも。プロンプトが 1 つなら繰り返し回数も指定できます。 |
| **4 · 保存先と予算** | 保存フォルダー、ファイル名、任意の予算上限。必要になるまで折りたたまれています。 |
| **スレート** | モデル、プロバイダー、長さ、解像度、リクエスト数、開始フレーム、見積り料金と所要時間。「見積り・キューに追加」で送信される内容そのものです。 |

**レンダーキュー**は、最初のバッチを作るまで短いガイドを表示します。その後は**プロバイダーレーン**（状態、キーと同時実行数、送信の一時停止）、**バッチ**（バッチごとの進行バー、一時停止・キャンセル）、**ギャラリーと選別**、復旧操作をすべて備えたページ送りの**ジョブ**表が並びます。バッチ完了・要確認・キー待ちのブラウザー通知は、オンにするまで送られません。

| ギャラリーのキー | 操作 |
| --- | --- |
| **J** / **K** または **←** / **→** | 前 / 次のテイク |
| **Space** | 再生・一時停止 |
| **1** · **2** · **3** または **U** | 採用 · 不採用 · 未選別に戻す（採用・不採用の後は次の未選別テイクへ移動） |
| **Enter** | 拡大表示 |

採用テイクは黄色の丸で囲まれ、不採用テイクは暗くなり取り消し線が付きます。選別してもファイルは削除されません。

## バッチの作成と選別

[CSV 列・テンプレート・画像の対応付け](docs/BATCH_IMPORT.md)にコピー可能な例があります。

1. **モデルとキー：** プロバイダー・地域・モデルを選びます。互換サーバーは正確な URL、モデル ID、対応機能とリクエスト形式を指定してください。Model Studio はワークスペース専用ホスト名が必要です。その接続先の API キーを保存します。キーはサービスのメモリーだけに保持され、終了すると消去されます。再起動後は再入力してください。
2. **ショットを書く：** 空行で区切ったプロンプトを入力するか、UTF-8 CSV・テンプレート・画像フォルダーを取り込みます。各行に開始フレームを指定でき、モデルが対応する場合は終了フレームも指定できます。
3. **映像とテイク：** 「プロンプトごとのテイク数」（1〜20）で各プロンプト・各行を複数回生成して比較できます（ファイル名に `-t1`、`-t2`… が付きます）。選択肢は選んだモデルが対応するものだけが表示されます。
4. **見積り・キューに追加：** 確認画面で費用の見積もり、所要時間、プロンプト数 × テイク数を確かめてから送信します。不明な料金は「不明」と表示され、通貨は別々に集計されます。
5. **選別と書き出し：** 完成した動画はショット・テイクごとにまとめてギャラリーに表示され、キーボードだけで選別できます。採用 1 本あたりの推定費用を確認し、「採用テイクを書き出し（CSV）」で出力パス・プロンプト・モデル・設定・ショット/テイク・費用・SHA-256 を含む一覧を編集ソフトやチーム向けに保存できます（JSON や全テイク版は「その他の書き出し」から）。再生成は毎回確認が必要で、新たなプロバイダー料金が発生する場合があります。バッチ予算を超える再生成は受け付けません。

予算は今後のジョブ送信を見積もりで制限するもので、請求額の保証ではありません。残高不足やモデル権限エラーによる停止中も、送信済みジョブのポーリングとダウンロードは継続します。動画は元のバイト列を保ち、同名ファイルを上書きしません。

## 復旧とプロバイダー

生成要求の結果が不明なジョブは**要確認**（`needs_review`）となり、自動で再送信されません。プロバイダーの管理画面を確認してから、ジョブの「結果を確認」で「既存のリモートジョブを関連付け」「未作成を確認済み → 再送」「追跡を終了」のいずれかを選択してください。追跡の終了は返金やリモート処理のキャンセルではありません。実行中・ダウンロード中のジョブも「追跡を終了…」できます（誤ったリモート ID を関連付けた場合など）。プロバイダーが 15 分間途切れずに 404/410 だけを返した実行中ジョブは `remote_not_found` で失敗となり、リモート ID は確認用に残ります。残高不足を含むその他の 4xx は、受理済みジョブのポーリング・ダウンロードでは再試行され、支払い済みの結果をすぐに破棄しません。

Gemini は `background: true` で interaction ID を先に保存し、再起動後もポーリングを再開します。ID を受け取る前に通信が切れた場合は、手動確認が必要になる可能性が残ります。OpenRouter はモデルが対応を宣言した場合にローカル画像を data URL で `frame_images` に渡し、モデル一覧の機能と料金に従います。長さ・解像度・アスペクト比を宣言しないモデル（現在は動画編集、アップスケール、トーキングアバター向けのモデル）は一覧に表示しません。ByteDance 系モデルのトークン料金は OpenRouter が公開する計算式（高さ × 幅 × 秒数 × 24 / 1024）で見積もります。OpenRouter へのリクエストには videogen を示すアプリ帰属ヘッダー（ユーザーデータなし）が付きます。`VIDEOGEN_OPENROUTER_ATTRIBUTION=0` で無効化できます。Google は Gemini API の Veo 3.1 プレビューモデルの最短の提供終了日を 2026-10-22 とし、後継に `gemini-omni-1.1-flash` を挙げています。Veo は OpenRouter 経由で引き続き利用できます。Volcengine / BytePlus Ark の Seedance 2.5 は ByteDance の API リファレンスでシード非対応のため、シード欄を表示しません。

対応先は OpenRouter、Gemini、Alibaba Cloud Model Studio、Volcengine / BytePlus Ark、設定済みの OpenAI 互換サーバーです。アカウント、地域、モデルの許可、料金は各サービスの条件に従います。プロバイダー情報は 2026-10-11 に再確認しました。[機能・料金と地域条件の詳細（英語）](README.md#providers-and-estimates) · [プロバイダー仕様](docs/providers/)

## ローカルデータと開発

プロンプト、参照画像、タスク状態、選別結果、出力パスはローカルに保存されます。生成時には選択したプロバイダーにプロンプト・画像が送信されます。プロジェクト運営のクラウド、テレメトリー、更新チェックはありません。フォルダーを共有する前に私的データがないことを確認してください。[プライバシー](PRIVACY.md)

`VIDEOGEN_DATA_DIR` と `VIDEOGEN_OUTPUT_DIR` で保存先を変更できます。プロキシには `HTTP_PROXY`、`HTTPS_PROXY`、`NO_PROXY` を使用し、ローカル通信はプロキシを迂回します。詳細は [英語版](README.md#proxy-configuration) を参照してください。

```bash
npm test
npm run test:e2e
```

テストはローカルの模擬サービスを使用し、有料 API を呼び出しません。

## よくある質問

**videogen は動画生成モデルですか？** いいえ。ローカルのクライアントとキューです。プロンプトとフレームを選んだプロバイダーへ送り、ジョブを追跡して結果を保存します。品質、コンテンツ規約、提供状況、料金はプロバイダーによります。

**費用はかかりますか？** videogen 自体は無料の MIT ライセンスです。プロバイダーが受理したジョブには、そのプロバイダーの料金が発生する場合があります。スレートと確認画面で先に見積もりを表示します。自前の OpenAI 互換サーバーならプロバイダーへの支払いはありませんが、モデルを動かせるハードウェアが必要です。

**スマートフォンや別の PC から開けますか？** 直接は開けません。サービスは `127.0.0.1` だけで待ち受けるため、同じネットワークの他の端末からは接続できません。狭い画面のレイアウトは、同じ PC 上の小さなブラウザーウィンドウ向けです。

**ブラウザーを閉じたり再起動したりしたら？** タブを閉じても影響はなく、サービスが処理を続けます。サービス自体が止まった場合は、再起動してキーを入力し直せば既知のジョブが再開し、確認なしに二重作成されることはありません。

**旧 Sora のジョブは引き継げますか？** Sora 2 API は終了しているため、旧リモートジョブは再開できません。ダウンロード済みの動画とプロンプトをバックアップし、[移行ガイド](docs/MIGRATING_FROM_SORA.md)に従ってください。
