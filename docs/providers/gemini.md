Implementation decision: use `createMode:"blocking"` and `supportsIdempotencyKey:false` until Omni background execution is verified. Mark this recovery limitation prominently: **a Gemini job interrupted during create cannot be recovered automatically and may already have been charged**. A timeout, reset or missing ID requires review. Once an interaction ID has been returned, save it immediately; subsequent polling/download must never recreate the job. Prefer URI output; reject unexpectedly large inline responses rather than buffering video.

Use a same-origin authenticated Files request. The resumable upload session is a returned URL, so validate its origin and do not forward credentials to another host. Do not copy documentation's query-key examples.

The implementation stores `remote.pollingUrl` as the Files metadata address in the same durability barrier as `remote.id`. A restored job polls Files directly and never requests the interaction's inline video. Manual association requires `files/<id>` or a same-origin Files URL; an interaction ID alone is insufficient. If a create response has an accepted ID but an absent or unsafe URI, retain the ID, then fail polling with the recovery limitation. Never issue another create automatically.

Uploads happen before paid create. Active remote image references remain in memory with their expiry; a restart uploads again when needed. The app supports one first frame, and does not expose last-frame/video editing. Audio remains enabled because no verified audio-off field was established. Gemini rejects an explicit silent setting and unsupported seed. Timeouts are 600 seconds, or 1200 seconds for 4K. Prices in the catalog are video-output estimates only; unknown resolution factors stay unknown.

## Availability and usage terms

✅ Mainland China is absent from the supported-region list. The terms require users to be at least 18 and describe professional/business developer use rather than consumer use; EEA, UK and Swiss clients must use paid services. [Available regions](https://ai.google.dev/gemini-api/docs/available-regions); [Gemini API terms, effective 2026-03-23](https://ai.google.dev/gemini-api/terms).

✅ Omni restricts editing/extending uploaded videos in the EEA, Switzerland and UK, and restricts edits of minors' images there. Do not describe this as a blanket ban on every first-frame image upload. Preserve the returned file and its SynthID metadata. [Omni guide](https://ai.google.dev/gemini-api/docs/omni).
