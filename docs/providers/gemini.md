Veo note (checked 2026-10-09): Google's [deprecations page](https://ai.google.dev/gemini-api/docs/deprecations) removes `veo-3.1-generate-preview`, `veo-3.1-fast-generate-preview` and `veo-3.1-lite-generate-preview` from the Gemini API on 2026-10-22 and names `gemini-omni-1.1-flash` as the replacement. This app never shipped a direct Veo lane; Veo 3.1 models remain available through the OpenRouter lane.

Implementation: `createMode:"async"`, `background:true`, `store:true`, and `supportsIdempotencyKey:false`. Create returns as soon as an ID is parsed, with no subsequent network request before scheduler fsync. A timeout/reset before receiving the ID remains an unknown outcome requiring review. This cannot be eliminated without provider idempotency or reconciliation. There is no automatic fallback to synchronous create or another generation request.

Use a same-origin authenticated Files request. The resumable upload session is a returned URL, so validate its origin and do not forward credentials to another host. Do not copy documentation's query-key examples.

Recovery accepts a `v1_...` interaction ID or a legacy `files/<id>` / same-origin Files URL. Existing saved Files URLs still poll directly. Otherwise the adapter replays SSE in 30-second windows, resolves the video URI, and checks Files state before download. Stream events are bounded to 1 MiB and each replay to 8 MiB. Unsafe URLs, mismatched IDs, and completed responses without a URI remain recoverable polling errors; no inline video is buffered.

Uploads happen before paid create. Active remote image references remain in memory with their expiry; a restart uploads again when needed. The app supports one first frame plus one optional last frame. Audio remains enabled because no verified audio-off field was established. Gemini rejects an explicit silent setting and unsupported seed. Background-create timeout is 60 seconds for every resolution. Prices in the catalog are video-output estimates only; unknown resolution factors stay unknown.

## Availability and usage terms

✅ Mainland China is absent from the supported-region list. The terms require users to be at least 18 and describe professional/business developer use rather than consumer use; EEA, UK and Swiss clients must use paid services. [Available regions](https://ai.google.dev/gemini-api/docs/available-regions); [Gemini API terms, effective 2026-03-23](https://ai.google.dev/gemini-api/terms).

✅ Omni restricts editing/extending uploaded videos in the EEA, Switzerland and UK, and restricts edits of minors' images there. Do not describe this as a blanket ban on every first-frame image upload. Preserve the returned file and its SynthID metadata. [Omni guide](https://ai.google.dev/gemini-api/docs/omni).
